# A. E. Waite, «The Pictorial Key to the Tarot» — канонический источник значений

Книга автора колоды Райдера–Уэйта, иллюстрации Памелы Колман Смит; первое издание 1910 года (Rider, London;
на титуле 1911). Общественное достояние: Уэйт умер в 1942 году, Смит — в 1951 году; книга опубликована до 1931 года.
