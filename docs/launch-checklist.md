## 5. Поисковые системы — 14.12 (В, по шагам)

Карта сайта уже названа в `robots.txt` — её читают Google, Bing и Яндекс; пинг карты Google отключён, поэтому
второй канал — регистрация в Search Console (книга 2027, 2.4.3, стр. 100).

**Google Search Console**
1. https://search.google.com/search-console → «Добавить ресурс» → **Доменный ресурс** → `arcanadiary.com`.
2. Google покажет запись TXT. Cloudflare → DNS → Records → Add record: Type `TXT`, Name `@`, Content — из Google.
   Вернуться в Search Console → «Подтвердить».
3. «Файлы Sitemap» → `https://arcanadiary.com/sitemap.xml` → «Отправить».
4. «Проверка URL» → главная `https://arcanadiary.com/` → «Проверить страницу на сайте» (живой тест: Googlebot должен
   получить страницу, а не `403` — Cloudflare/WAF может резать бота при правильном robots.txt; книга 2027, 2.3.3) →
   «Запросить индексирование». Так же для `/es`, `/cards`, `/es/cartas`. Не больше нескольких ключевых страниц:
   остальные Google найдёт по карте и ссылкам (общее правило Search Console, в базе знаний отдельной записи нет).
5. Google Cloud Console → OAuth consent screen → **Publish app** (теперь ссылка на политику открыта).

**Bing Webmaster Tools**
1. https://www.bing.com/webmasters → войти → **Import from Google Search Console** (подтверждение и карта сайта
   переносятся сами). Если импорт недоступен — Add site, подтверждение TXT-записью в Cloudflare, затем Sitemaps →
   `https://arcanadiary.com/sitemap.xml`.
2. По желанию: Cloudflare → Caching → Configuration → **Crawler Hints** — On (Cloudflare сам сообщает Bing и Яндексу
   об изменениях через IndexNow; общее знание, в базе знаний записи нет).
