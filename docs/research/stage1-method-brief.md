## Ключевые правила

- Новый URL — только при совокупности: самостоятельная задача, отдельное обещание, существенное отличие, свои условия/доказательства, нет высокой смысловой идентичности, понятная роль в пути, реально сделать качественно (стр. 620–621).
- Смена заголовка без смены ответа — не новая задача; «больше исследовать» — не действие (стр. 627).
- Выдача — свидетельство, не структура; правило «совпало N URL = одна страница» отвергнуто; органику считать отдельно от спецблоков; цепочки А~Б~В проверять по краям (c07.05).
- Частотность ≠ важность; объёмы разных регионов в одну колонку не сводить; ноль ≠ отсутствие данных (7.2.1, 7.2.4).
- Метки интентов — только ориентир, рядом человеческое описание задачи (c07.04).
- Вывод: «карта × контекст» — модификаторы; каждый доказывать на уровне типа страницы записью решения (стр. 629).

## Мультиязычность

- Корпусы EN и ES раздельные; ES собирается сам по себе, не переводом EN (7.2.3, вывод).
- Снимки выдачи — отдельно на каждый рынок (7.5.2).
- hreflang (c02.10, стр. 140–146): только эквиваленты 1:1, связи по таблице Entity_ID, коды `en-US`, `es-MX`, `x-default`, без гео-редиректов по IP.

## Пробелы

- Нет GSC: опора на продукт, язык пользователей, внешние источники; поисковую историю не имитировать (7.2.1).
- Снимки выдачи — Ahrefs SERP overview со страной и датой; без подтверждённых условий — только разведка (7.5.2).
- Стоимость поддержки ~1 500 страниц — оценка по каждому типу, неизвестное = «неизвестно», не ноль (7.11.2).
