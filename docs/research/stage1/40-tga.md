## Как читать

- **Одна запись — один кандидат:** тип страницы × язык (`TGA-EN-<type_id>`, `TGA-ES-<type_id>`, 24 записи) и
  подзаписи там, где внутри типа нужны отдельные решения (суффикс после `type_id`). Для `card-context` — сводная
  запись типа и пять подзаписей по модификаторам (`-reversed`, `-love`, `-yes-no`, `-feelings`, `-advice`) на
  каждый язык. Полный список — «Сводка записей».
- **Поля записи** — порядок стр. 629: **Решение** → **Основание** → **Альтернатива** (и когда к ней вернуться) →
  **Перед написанием** → **Граница**. Внутри основания — два теста стр. 620–621:
  **Тест 1** — «Человек откроет эту страницу, чтобы…» (достижимый результат);
  **Тест 2** — «Чего пользователь не получит из существующего документа?»;
  и **встраивание / удаление** — пробное встраивание (место, нужен ли основной аудитории, помогает ли решению, не
  меняет ли обещание, не вытесняет ли ответ) и тест удаления (стр. 624–625). **Оспаривание** (стр. 628) — где
  решение могло пойти в другую сторону.
- **Значения поля «Решение»** (для задачи 12) и форма книги, которой они соответствуют (стр. 622):
  `самостоятельная страница` — отдельная задача с собственными условиями и данными;
  `раздел` — обязательный раздел или дополнительный блок принимающей страницы (названа в записи);
  `доработать` — добавить содержание в план уже принятой страницы, задача которой та же;
  `имеющийся ответ` — ответ уже даёт другая наша страница, нужен понятный переход;
  `отклонить` — новый URL или содержание в предложенном виде не создаём, причина названа; сама потребность не
  объявляется несуществующей (стр. 627);
  `получить данные` — «пока не установлено»: названа конкретная проверка и результат, который изменит решение
  (стр. 627–628).
- **Правило «ждёт снимка» (v1.1, для всех записей).** Если решение зависит от проверки выдачи, которая ещё не
  сделана, и названный дешёвый снимок может его изменить, решение — `получить данные`, а в записи есть:
  (а) точные запросы снимков, которые решают вопрос; (б) временная форма на запуск («пока — раздел на странице
  карты»); (в) какой результат ведёт к какому решению. У таких записей строка о конфликте с владельцем звучит
  «конфликт не установлен — ждёт данных»: конфликт не утверждается, пока нет данных. Правило не применяется, когда
  решение держится на сравнении планов ответа (стр. 621) или на роли в пути, а снимок — только условие возврата в
  «Альтернативе»; такие записи сохраняют решение. Все снимки сведены в раздел «Снимки, которые закрывают
  `получить данные`» в конце файла.
- **«Существующий документ».** Сайта ещё нет. Принимающая страница — та, у которой в этом файле решение
  `самостоятельная страница`; её содержание — по плану продукта. Поэтому все решения о поглощении предварительные
  (стр. 626: без фактического текста принимающей страницы результат только предварительный) — их перепроверяют
  по тексту страницы на этапе GIST (стр. 630 и далее).
- **Волна** — очередь плана продукта (план, «Функции по очередям» и «Сайт и страницы»): MVP = `запуск`, затем
  `V1.1`, `V2`, `V3`. Для `отклонить` и `получить данные` — волна типа по плану (страница в ней не создаётся или
  ждёт проверки). Где доказательства расходятся с очередью, это записано строкой «Расхождение с очередью».
- **Спрос** — Ahrefs Keywords Explorer, дата данных 10.11.2026; страна при каждом числе (US или MX); справочные
  числа других испаноязычных стран — `corpus/ahrefs/es-by-country.csv`, не суммируются. `нет данных` — запрос
  не вернулся или не собирался. Снимки выдачи и их даты — в записях групп `20-groups-en.md`, `20-groups-es.md`
  (v1.2), на которые ссылается каждая запись. Матрицы — `corpus/ahrefs/card-context-us.csv`,
  `corpus/ahrefs/card-context-mx.csv`; «доп. расчёт задачи 11» — подсчёт по той же матрице 11.11.2026 (лучший
  объём шаблона на карту). Ahrefs и веб в этой задаче не вызывались.
- **Карточки `OPP-NN`** — `30-opportunities.md` v1.1. OPP-15 (шпаргалка / PDF) и OPP-21 («ввести свои карты») —
  гипотезы без проверки выдачей: здесь только как гипотезы, основанием `самостоятельная страница` не служат.
- **Запреты З1–З6** (`10-task-map.md`, «Запрещённые утверждения») действуют в каждом «Перед написанием».
- **Объём страниц** (180 к запуску, около 1 500 к неделе 13, 390 «карта × контекст» на язык и т. д.) — решение
  владельца (паспорт). TGA его не пересматривает. Где TGA даёт `раздел` или `отклонить`, а в плане отдельные
  страницы, в записи стоит строка **«Конфликт с решением владельца»**: что хочет план, что говорят доказательства,
  конкретный риск и наблюдение после запуска, которое покажет, что риск сбылся. Решает владелец.
- Общие для конфликтов наблюдения — по книге, 4.8.1: выпуск отдельного URL блокируется, если вопрос закрывается
  блоком 150–200 слов внутри проиндексированной страницы (стр. 380); страницы выпускаются волнами по 10–20 URL с
  контролем доли «Просканирована, но сейчас не проиндексирована» в отчёте «Индексирование → Страницы» Search
  Console (стр. 381); раздел, накопивший высокий спрос на позициях 10–25, — признак выноса в отдельный документ
  (стр. 379). Каннибализация видна в отчёте «Эффективность»: фильтр по запросу → вкладка «Страницы», показы
  делят или переключают два наших URL.
- Адреса, родители и перелинковка здесь не назначаются (стр. 629); это задача 12 и этап кокона.

## 1. home — главная-инструмент

### TGA-EN-home — бесплатный расклад онлайн

- **Решение:** `самостоятельная страница` — главная EN как инструмент расклада на свой вопрос. **Волна:** запуск
  (план, «Сайт и страницы»: главная-инструмент, MVP).
- **Основание:** EN-G01 (проверена выдачей): `tarot reading` (38000, US), `free tarot reading` (20000, US),
  `tarot card reading` (16000, US), `free tarot card reading` (7800, US); ядро и край `free 3 card tarot reading`
  (1000, US) делят 3 общих URL, органика — инструменты расклада. Число карт — формат внутри инструмента, не повод
  для отдельного адреса (EN-G01, «Значимые условия»). Условия стр. 621 выполнены: своя задача и обещание,
  своя роль (вход в продукт), качество достижимо (план, «Как устроен ИИ-чтец»).
- **Тест 1:** человек откроет страницу, чтобы прямо сейчас бесплатно и без записи к живому чтецу получить
  расклад на свой вопрос с толкованием.
- **Тест 2:** других страниц ещё нет; соседние типы дают узкий формат (одна карта, да/нет, любовь), а не расклад
  на произвольный вопрос с выбором числа карт.
- **Встраивание / удаление:** это принимающая страница для TGA-EN-home-ai, -trust, -questions. Без неё ядро
  EN-G01 остаётся без документа.
- **Альтернатива:** сильной нет.
- **Перед написанием:** первый расклад без регистрации — требуемый уровень (К-01, К-02; OPP-07); формулировки
  без «accurate» (З1) и без предсказаний (З2); вопросы о здоровье, беременности, смерти, суде переводятся в
  размышление (З3; план, «Как устроен ИИ-чтец»).
- **Граница:** живой чтец и офлайн — `psychic reading` (6000, US), `tarot reading near me` (3400, US) — вне
  продукта (EN-G01, «Исключено»); кнопка партнёрки — не содержание страницы.

### TGA-EN-home-ai — расклад от ИИ

- **Решение:** `доработать` — задачу EN-G02 закрывает главная; в её план добавить: чтение делает ИИ на своей базе
  значений, можно задать уточняющий вопрос. **Волна:** запуск.
- **Основание:** EN-G02 (частично, один снимок): `tarot ai` (5900, US), `ai tarot reading` (3700, US), `ai tarot`
  (3400, US), `ask tarot ai` (600, US), `ai tarot chat` (600, US); `tarot ai` ~ `free tarot reading` — 2 общих
  URL из 9 / 9, ~ `tarot reading` — 0; органика — продукты-чтецы. Выдача отдельной страницы не требует (EN-G02,
  «Предложение»). Сравнение двух планов ответа (стр. 621): «вопрос → вытягивание → толкование ИИ → уточнение» —
  одна последовательность и одни данные; наш продукт и есть ИИ-чтец (план, «Функции по очередям»), `ai` —
