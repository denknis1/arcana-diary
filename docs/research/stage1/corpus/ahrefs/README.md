# Корпус Ahrefs — как читать

- `volume = 0` — значение, которое вернул Ahrefs: запрос найден, спрос ниже порога оценки сервиса. Это не
  отсутствие данных. Отсутствие — `нет данных` (7.2.1).
- `rank` — позиция в ответе того инструмента, где запрос встретился впервые (matching 1–60, related 1–15,
  suggestions 1–15); это не сквозной рейтинг файла. Сквозной порядок — сортировка по `volume`.
- `source_tool=related` в `us/` — в основном общие одиночные слова (card, love, free): для карты задач не
  используются. Для `mx/` related не собирается (поправка 4 плана).
- В сырых данных есть запрещённые темы (беременность, смерть, болезни): не фильтруются при сборе; отсеиваются в
  `10-task-map.md`, раздел «Исключения и запрещённые утверждения».
- `ledger.csv`, колонка `units` = `units-cost-total-actual` из ответа Ahrefs. Строки task 3 с `vol>=20 limit150` —
  первый заход по исходному методу (до поправок).
- `es-by-country.csv` — 97 верхних MX-запросов (не 100: бюджет, отсечка внутри равенства volume=200).
  Английские формулировки `tarot`, `tarot cards`: значение `volume_us_es` у них — англоязычный спрос в США, не
  испанский; для выводов по испаноязычным в США не использовать. Шум (не таро-спрос): `taro bebida` (напиток),
  `arcano 8` (не про карты таро) — в группы и карту не берутся; строки оставлены, чтобы не ломать отбор по объёму.
- `rank` в файлах типов не монотонен по `volume` (позиция в исходном инструменте); сквозной порядок — по `volume`.
- Сверка переноса (10.11.2026): 60 случайных запросов (20 из `card-context-us.csv`, 20 из `card-context-mx.csv`,
  20 из `mx/*.csv`) перезапрошены через `keywords-explorer-overview` — 60 из 60 объёмов совпали.
- `../competitors.csv`, колонка `volume` — объём из Site Explorer (отчёт organic keywords), он расходится с
  Keywords Explorer для того же запроса (сверка 10.11.2026: 12 из 20 различий, например «imagenes simbolicas»
  250 против 70). Перенос проверен повторным запросом tellmytarot.com (15 из 15 строк совпали). Для спроса брать
  объёмы корпуса (`us/`, `mx/`, `card-context-*`), из `competitors.csv` — только позиции, URL и роли страниц.
- `../reddit/questions.md` — Reddit вернул 403 на все 4 запроса (одна попытка); вопросы взяты из уже купленных
  выгрузок Ahrefs `us/questions.csv` и `mx/questions.csv`. Голоса аудитории другого типа источника (форумы,
  обсуждения) в корпусе нет — это ограничение для проверки по источнику другого типа (c07.03).
- Повторная сверка (11.11.2026, независимая выборка): 39 случайных запросов из `us/*.csv`, `mx/*.csv`,
  `card-context-us.csv`, `card-context-mx.csv` — 38 объёмов совпали, 39-й (`diez de oros sentimientos`) Ahrefs
  не вернул, в корпусе у него `нет данных`. Целостность: дубликатов внутри файлов нет, все 59 снимков выдачи
  читаются, 12 типов × 2 рынка покрыты, 78 карт × контексты покрыты.
